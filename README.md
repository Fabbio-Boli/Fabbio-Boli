# Olá, eu sou o Fabbio Boli 👋

**Desenvolvedor de Software | Engenharia da Computação**

Sou um programador apaixonado por resolver problemas reais através da tecnologia, construindo desde aplicações mobile completas até sistemas de automação IoT e Gémeos Digitais (Digital Twins). Procuro sempre criar soluções eficientes que unam hardware e software.

- 🎓 Estudei Engenharia da Computação na FIAP e possuo especialização em Web Design.

- 💡 Experiência em projetos multidisciplinares avançados, envolvendo integração de hardware (ESP32, Raspberry Pi), plataformas Cloud (AWS) e motores gráficos (Unreal Engine 5).
- 📍 A residir em São Paulo, SP.
