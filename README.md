**Desenvolvedor de Software | Engenharia da Computação**

Sou um desenvolvedor apaixonado por resolver problemas do mundo real através da tecnologia. Tenho experiência na construção de soluções completas, desde aplicações mobile (como o **Nutri Nex**) até sistemas de automação IoT e Gêmeos Digitais.
